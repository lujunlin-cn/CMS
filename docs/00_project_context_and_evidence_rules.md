# 共用背景、指标与证据规则

整理日期：2026-11-07。本文供其他路线文档共同引用，也可单独上传 GPT。

## 任务和数据

胸部 X 光多标签分类；一个患者 Subject 有多次 Study，一个 Study 有一张或多张图。最终对每个 Study 输出 10 个独立疾病概率，不能用互斥 softmax 解释十类。

| 划分 | Study | 图像 / 患者 | 用途 |
|---|---:|---|---|
| 官方 Train | 18,513 | 30,343 图 / 11,055 患者 | 训练、Train 内部开发划分 |
| 官方 Valid | 859 | 1,422 图 / 228 患者 | 长期反复用于开发，已有选择偏倚 |
| 官方 Test | 1,414 | 136 患者 | 无标签，最终冻结推理；不拟合统计或参数 |

官方 Train/Valid/Test 的患者隔离审计与后来内部 CV 的泄漏是两件事：官方划分没有因此失效，v3 自建划分却存在患者重叠。

## 指标必须说明评价人群

- **Study Macro-AUC / macro10**：每 Study 一行预测、十类 AUC 等权平均。多数近期标准协议先逐图 sigmoid，再 Study 内 mean_prob；max/LSE 等历史协议单独标注。
- **heavy9**：先在指定完整 cohort/固定 manifest 中计算患者不同 Study 数，取 pn≥9 的 Study，再对九个异常类 0–8 计算宏 AUC。官方 Valid 为 436 Study / 23 患者；它是工作代理，不是官方评分公式。
- **AP-single×heavy**：Study 恰有一张 AP 图，并属于固定 heavy 患者；官方 Valid 为 255 Study。筛子集后不重新算 pn。
- **hn9 / hard-negative AUC**：阳性与“其他异常阳性但本类阴性”比较；不是 heavy9。
- **Test-matched / matched**：历史按可观测协变量重加权的诊断。版本、单元格和规则不同，不可混为同一指标，也不能默认可用 Test 统计拟合。
- **图像 Macro-AUC**：不能与 Study Macro-AUC 对比。一个 Study 多图时会被重复计权，且图像排序不等于聚合后的 Study 排序。

跨子群的 AUC 还包括跨群正负对，不能按群比例线性加权子群 AUC 推导 overall。全局逐类严格单调映射不会改变该成员 AUC；进入集成后才可能改变成员的相对影响。

## 证据分级

1. **可复核结果**：有实际指标/预测与可追溯配置，评价范围明确。仍可能是探索性结果。
2. **受限证据**：有指标，但预算、初始化、预处理或评价集不匹配，不能单变量归因。
3. **协议无效**：训练/验证重叠、错误 mask、错误初始化、flag 没进入 loss 等；不能评判原方法。
4. **技术失败 / 中止**：OOM、非有限值、缓存缺失、断言失败；没有完成的训练不能叫方法负结果。
5. **计划 / 门控跳过**：代码或方案存在，无有效执行证据；不计为完成实验。

所有表中 AUC 用 0–1；+0.01 是 +1 个百分点，不是 +0.01 个百分点。患者 bootstrap 的正差比例不是 p 值，也不是方法正确的后验概率。历史单次 seed 差约 0.012，不能把它升级为已估计的普遍噪声标准差。固定 checkpoint 的置信区间没有自动校正反复选 epoch、组合和方案的偏倚。

## 不能再沿用的诊断

- “X21 全用 stretch，心胸比畸变导致失败”：错误，源码使用 contain。X59 的 stretch 是另一个配置，不能反推 X21。
- “X35 的 AbnNeg 已验证无效”：原版 soft target 被丢弃，未真正实施；X45 才是修复版。
- “EA 证明 cosine 不行”：EA 同时是 Small224/encoder LR×0.1；X21 的匹配配方后来有效。
- “X92 0.85 是突破”：原版 Study/DICOM 100% 验证重叠；修复版仍有患者重叠。
- “A 系列 Freeze 很差说明三轮不够”：旧版从 ImageNet 冻结，不是 X21；应看 `_FREEZE_X21`。
- “模型共同失败证明错标/没有可见病灶”：没有独立阅片人，无法得出该结论。
- “AP 专家一次失败证明 AP 不可学”：只反驳该训练与数据配置；后续异构 AP 成员仍有局部互补。

## 约束与尚缺材料

项目按非医学公开预训练、赛方数据、解压后加载文件合计≤500 MB、T4 单图端到端≤100 ms 的工程约束推进。规则文件保留历史版本及争议，应核对其末尾修订，不能将旧“100 秒”当现行标准。训练集对比式自监督、Test 元数据密度比等历史方案存在合规疑点，记录它们不等于认可其可提交。
