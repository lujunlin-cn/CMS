当前最值得推进的比赛路线是：ConvNeXt-Small 为主模型，DenseNet121 为优先互补模型，ConvNeXt-Tiny 为效率与备选分支；先统一推理精度、Study 监督和聚合口径，再做损失及微调消融。U-Net + MIL 应继续研究，但应先恢复 encoder 全局信息通路，并以受控结构比较和对强模型的集成增量证明价值。

1.1 最重要的五项判断

  1. 【已验证】用户给出的七模型排名成立。 全量预测的 U-Net AUC 是 0.724071；训练日志最佳值是 0.724158，因此摘要中的 0.7242 可以追溯到训练验证口径。不要混用两套数值判断微小收益。
  2. 【已验证·探索】Small + DenseNet121 等权概率平均达到 0.794062，较 Small 增加 0.007552。 这是无需新训练即可复核的首选候选；同一 Valid 上十类 AUC 都没有下降。最终是否采用还取决于统一精度后的复验及实际部署约束。
  3. 【已验证】高 F1 不代表高比赛排名。 Small 第 3→5 轮，AUC 从 0.786539 降至 0.763885，而 F1 从 0.331981 升至 0.355565。现有 best.pt 已按 AUC 保存；应补的是“完全同 AUC 时比较 F1”，不是推翻现有主指标。

【已验证】六基座都是五轮、224 输入、image batch 32、AdamW、初始 LR=3e-4、weight decay=1e-4、seed=20261024，未启用水平翻转。训练逐图 BCE，验证按 Study 最大概率聚合。U-Net 使用 Study batch 4、LR=1e-4、空间 top-20%、Study mean-logit、BCE、encoder 全量更新、五轮；没有启用增强、ASL、加权 BCE、warmup 或分层 LR。D06 D09

3.3 精度与检查点

【已验证】原训练 evaluate() 未开 autocast；全量推理在 FP16 autocast 中执行 sigmoid，之后才 .float()。全部预测都落在 FP16 格点上（容差 1e-12），保存为十进制或 FP32 不会恢复已经丢失的精度。当前排名不受微小差异影响，但 10^-4 量级消融必须统一精度。D05 D06

补丁将概率计算改为 torch.sigmoid(logits.float())，默认评估前向关闭 autocast，并导出基座逐图 FP32 logits。训练可以继续 AMP。若最终用 FP16/INT8 部署，应对完整最终推理路径在 Valid 重新验证，不能把 FP32 分数直接归给低精度部署模型。所有库版本、预处理、聚合、推理 dtype 与 checkpoint hash 必须一同记录。

5.3 标签相关性：软建模，不写死医学规则

【已验证】Train/Valid 的 No Finding 不与其他九类正标签共现；但这不意味着十个概率必须总和为1，也不意味着 No Finding 能用 1−max(p_disease) 无损替代。其他病种可共现；标签相关性既有医学关系，也有采集和标注过程影响。

5.5 增强：先低幅度，再强弱组合

【待验证假设】当前强基座没有有效增强，适度像素扰动可能改善过拟合。首轮候选是亮度偏移±.03、对比度系数[.9,1.1]、灰度共享Gaussian noise σ=1/255，均在[0,1]原像素域定义，clip后再normalize；先逐项测试。它们是“低幅度候选”，不是已验证的医学安全保证。只扰动原图有效区域，不让padding亮度成为随机特征。

第二轮可让50% Train样本使用原始弱增强、50%使用获胜增强，不默认双前向一致性。几何旋转预设±5°、小幅平移时保留全胸；大裁剪、垂直翻转、左右颠倒、强弹性变形、强锐化或擦除胸膜边缘风险更高。即便十类没有左右标签，水平翻转仍可能改变解剖与文字关系，应独立消融。

Mixup/CutMix有通用文献和规则许可，但标签插值未必符合胸片病灶可见性；CutMix容易移除局灶却保留整Study阳性标签，Mixup可能稀释稀有阳性。它们放在第二阶段，先小α=.1并以相同Train图像预算比较。R17 增强后高F1、低AUC仍算主任务退步。

5.6 校准、阈值、集成与 stacking

校准顺序： 先固定主模型/ensemble概率，再用Valid患者分组交叉拟合温度和Gate。报告NLL、Brier、校准曲线，避免只报分箱ECE；第一目标依旧是AUC。温度缩放有经典依据，但正温度的单调性决定了它不能直接提高同一单模型的排序。R18

十个独立温度和十个精细阈值在c1仅16位阳性患者时很不稳定。先单一温度或受正则的逐类温度；Gate使用小的预设候选或向全局阈值收缩，并记录患者折间波动。后处理交叉拟合只能减少后处理拟合偏差，无法消除基座已在全部Valid选checkpoint的偏差。不要把这种输出称作真正未见验证集的OOF泛化成绩。

集成优先级： 先Small+Dense等权概率，再比较Small/Tiny/Dense三模型的等权概率与等权logit；MIL只试预设小权重。逐类混合权重会引入较多自由度，当前Valid不适合大网格搜索。温度在各模型平均之前应用会改变混合排序，属于新ensemble模型，不能引用“温度不改变AUC”来免做验证。

Stacking只有在能承受额外训练时再考虑：用官方Train内部患者分组的OOF基座预测训练小型、强正则meta learner，再在官方Valid选策略；不能用基座在Train的拟合预测训练meta层。外部教师/外部标签不进入此流程。以七模型×十类交叉特征在228位Valid患者上直接拟合MLP，属于高过拟合风险方案。

asc=softmaxs∈M{wcT[tanh(Vhs)⊙σ(Uhs)]},zc=∑s∈Mascesc. a_{sc}=\operatorname{softmax}_{s\in M}\{w_c^T[\tanh(Vh_s)\odot\sigma(Uh_s)]\}, \quad z_c=\sum_{s\in M}a_{sc}e_{sc}.

文献支持可学习集合聚合；该具体逐类胸片设计和目标类别改善仍是假设。首轮不同时加入标签图、view embedding、TV或稀疏正则。

Study层先用mean-logit/mean-prob/max/LSE，之后再从每图视觉特征学习class-specific权重。缺失视图不填成可参与softmax的假图，保留实际counts；单图attention应退化成权重1。Study中的AP/PA/侧位并非独立观测，必须检验view权重是否只在利用拍摄协议。

Noisy-or： 1−∏(1−p_i)在同值p下也随图数增加，且同Study视图高度相关，不能默认适用。空间数千token上更易饱和。1−exp(mean(log(1−p_i)))是改变了含义的归一化变体，应明确公式，不能继续宣称是原始独立事件概率。Quantile用于1—2图Study时可退化为有限插值、随图数跳变；因此两者都放到第二阶段。

7.3 多尺度、高分辨率和弱监督证据图

【文献支持】ChestX-ray8、Schwab等胸片MIL提供无局部标注分类/证据建模先例。R19 R22 Attention U-Net另提供decoder与attention分类结构的参考；本轮仅核查作者实现与摘要，没有确认其完整局部监督来源，因此不把它作为完全不依赖局部标注的证据。R23 本项目可借鉴结构，不能引入这些研究的医学数据或权重。

【待验证假设】先从encoder末两三层生成轻量evidence，再与完整decoder比较，能判断收益是否需要U形重建。224输入已经丢失的细节无法由decoder恢复，因此高分辨率应单独验证；384更可能帮助c2/c3/c7，但也增加噪声、过拟合及T4时延。全图letterbox保留胸廓比例，局部patch路线必须保留全局分支，否则c1/c6可能受损。

Evidence map不是分割真值。 原仓库AdvancedUNetMIL.forward返回logits、evidence与几何mask，attention权重在内部计算后丢弃，不能把evidence输出直接称为attention图。新交付ResearchUNetMIL.forward仅返回logits；后续证据研究需显式增加evidence与attention两种导出，记录掩码范围和遮挡敏感性。没有病灶框/掩码，不能报告定位Dice/IoU。显著图看上去像肺也不能证明解释忠实；CXR显著图基准已有对可靠性的系统检验。R24

7.5 标签噪声、不确定性与 ensemble 定位

【文献支持】BoMD针对多标签胸片噪声提出描述符和重标注方法，但涉及语言模型语义，不能默认将其医学语义资产带入正式路线。R26 本仓库没有提供疾病标签的逐项不确定状态；Support Devices=-1只是设备字段，不能套用其他胸片数据集的U-Ones/U-Zeros到本任务。

正式路线保留原标签，先做轻度smoothing、置信分层和原始处理链复核。模型分歧、epoch波动、损失和敏感度只是审阅信号，不能直接合成“标签错误概率”。官方Train内教师/自蒸馏或soft label也会改变监督，至少需要单独合规核验和噪声消融；外部医学教师明确不纳入。

U-Net未来的两个成功标准分别是：在公平DenseNet结构对照中提高Macro-AUC；或者在冻结强模型组合上带来可复验的Macro-AUC增量。后一条可以成立而单模型仍不第一。视觉热图更漂亮、相关性更低或低阈值F1更高，都不能替代这两个标准。

8.2 敏感候选不等于原始攻击样本

【已验证】每个top_sensitive_valid.csv有100行，但只有9行标为candidate_top1pct=True；不能将全部100行称为“前1%攻击图”。study_20230与study_20430分别进入六模型前1%敏感列表，study_20349进入五模型；多条候选来自同一患者。应称为扰动敏感候选，按患者和官方标签组织人工复核，不能自动删除或改标签。

证明原始样本遭到攻击，需要可信原始图比对、来源与处理链、修改痕迹等独立证据。FGSM/PGD只是“能否构造一个导致预测变化的输入”的实验。阈值翻转也不是完整攻击成功率，原先错误的标签可能翻为正确。

8.3 修复与后续审计协议

交付补丁在 [0,1] 像素域优化，模型前向再normalize；记录实际L∞、CLI配置、随机起点和重启，保留最强BCE候选，修复Study attention加载。支持free_rgb/full与gray_shared/content两种独立威胁设置：后者只禁止通道色差与人工padding扰动，并不识别肺野或原图黑边。改变约束会改变攻击强度，不能当成模型训练变鲁棒。

预设ε={0,.5,1,2,4}/255，每档显式设置--step=ε/4（ε=0时step=0）；首轮10步、2次重启，候选再比较20步并核查收敛，保持步长、随机起点、重启数、seed和目标一致。不能沿用补丁默认2/255步长来扫所有小ε。报告clean/受扰Macro-AUC、每类AUC、概率/logit变化、NLL/Brier、真实L∞和分层；另做相同量级随机灰度噪声、轻模糊/JPEG/亮度对照。最坏方向扰动与常见成像损坏分开解释。AutoAttack文献支持避免弱攻击/梯度遮蔽误判，但标准多类实现需修改目标才能用于本十标签任务。R27 R28

补丁范围： 只支持原有七个检查点和其旧预处理路径；修复后仍保留基座逐图BCE、MIL Study BCE的目标差异，并写入元数据。要严格比较新模型或架构鲁棒性，需要另接统一的Study级攻击包装器。它不能直接加载新trainer的global/residual模型或新normalization；更不能保证提高clean AUC。

12. 两阶段计划与退出标准

第一阶段：快速验证、低成本、提高Macro-AUC的高优先级尝试

阶段1A：先确认已有收益。 用固定旧checkpoint统一FP32 Valid输出，复算Small+Dense、三模型平均和少量MIL权重；检查四种Study pooling。同步修复攻击审计口径，但不把鲁棒性调参混入clean选模。保留完整Valid与患者分层。

阶段1B：少量有明确对照的重训。 运行P0—P4、L1/L2、O1/O2、N0/N1。Small是损失/协议/微调主平台，EfficientNet只做normalization诊断；获胜改变先移植到Tiny，Dense保持互补基线。随后R0/R1测试高分辨率，U0/U1/U2作为自主结构的最小验证。

阶段1C：确认与冻结。 仅对最值得继续的一至两项与其匹配对照做三seed十二轮复核；记录每轮best、seed波动、患者簇区间、分层、实际时延和文件大小。冻结很少的ensemble候选后才做温度/Gate。最终测试前固定代码、权重、归一化、聚合、阈值与精度；不根据Test输出再迭代。

阶段一不能承诺某方法增加多少AUC。当前最坚实的量化起点是已有Small+Dense的探索增量；ASL、分层LR、Study监督和384都需要实际实验。

第二阶段：结构创新与论文级研究

围绕三个可证伪问题组织，不做任意模块堆叠：

  1. 预训练语义保留是否比完整decoder重建更关键？ 用U1/U4/U0/U2四组，统一encoder/优化，分析全局c1/c6/c10和局部c2/c3/c7；增加轻量多尺度作为效率对照，报告参数量与部署代价。
  2. 类别与视图自适应聚合是否改善稀有发现的排序？ 先空间mean/top-k/LSE/gated attention，后Study共享/逐类attention；比较随机类查询与Train共现图，做单独/共现、AP/PA、1/2/3+图分层。正则项与分辨率分开消融。
  3. 证据结构能否增加互补性并改善可诊断的稳定性？ 冻结强ensemble后加入MIL，检验跨seed增量；在统一Study目标、真实像素预算下做扰动和质量审计。无局部标注只讨论分类证据一致性，不把热图当定位精度或临床解释验证。

论文级结论至少需要同预算、患者独立、足够重复和清晰负结果。仅有官方Valid的当前研究不能声称外部泛化、临床有效或对真实攻击的检测能力；也不能为补齐论文而把外部数据带进正式比赛路线。DINO诊断、AUC直接优化、quantile/noisy-or、标签噪声训练均在上述主线稳定后再追加。
